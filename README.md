**ClientFlow is a proposed client relationship management application developed to provide a way for professional teams to maintain client information and organise client-related work. The project was selected from a practical problem observed through my previous professional experience. I have more than five years of experience working in a Data Analytics team, where maintaining accurate information in a CRM was important for tracking client activity, teamwork and the status of ongoing activities. Working with several clients at the same time made it clear that a reliable and maintained central record is essential. This experience influenced the choice of ClientFlow as a project because it connects real workplace need with software requirements, system design and implementation. **

**This apps **contain** the following features:**

* Signup
* Login
* Logout
* Update profile
* Add tasks
* View tasks
* Update tasks
* Delete tasks

**This **app**lication** is**almost **a** precompiled** app**. However, students will develop some features,**such as adding tasks, viewing tasks, updating tasks, and **deleting** tasks**. **Students** will interact with GitHub when they develop the features.**
